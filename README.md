# SHOPMART ORDER MANAGEMENT SYSTEM

ShopMart is a simple Java console-based application used to manage customers, purchases, refunds, and order history.

## Features

* Add new customers
* Store customer wallet balance
* Add purchases
* Process refunds
* View customer order history
* Display purchase and refund details
* Simple menu-driven console application

## Technologies Used

* Java
* OOP Concepts
* Array
* Scanner
* LocalDateTime

## How to Run

1. Clone the repository.
2. Open the project in VS Code or any Java IDE.
3. Compile the Java program.
4. Run the Main.java file.
5. Select the required option from the menu.

## Menu

1. Add Customer
2. Purchase
3. Refund
4. History
5. Exit

## Example

```text
===== SHOPMART =====
1.Add Customer
2.Purchase
3.Refund
4.History
5.Exit
```

## Purpose

This project was created to practice Java programming, classes, objects, arrays, methods, and basic console-based application development.
